Mastering LinkedIn for Career Growth - Landing Page

A functional, clean, and responsive website for a LinkedIn landing page focused to promote an online course on career growth for Indonesian professionals and job seekers.

Tools & Technologies Used
- HTML5: Main structure and content
- CSS3: Custom styling with CSS variables and modern layout techniques
- JavaScript: Interactive functionality for FAQ accordion and smooth scrolling
- Google Fonts: Inter font family for modern typography
- Responsive Design: Mobile-first approach with CSS Grid and Flexbox

Landing Page structure
- Hero Section: Includes title, short subtitle, and Call to Action button that leads to the bottom of the page
- About Section: 104 words to describe the course
- Key Benefits Section: Uses E.P.I.C. core values from BelajarLinkedIn's instagram page to highlight course advantages 
- Testimonial placeholder Section: (Not real) alumni success stories and reviews 
- Interactive FAQ Section: Accordion frequently asked questions section
