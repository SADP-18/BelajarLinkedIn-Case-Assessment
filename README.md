Mastering LinkedIn for Career Growth - Landing Page

A responsive landing page for a LinkedIn mastery course focused on career growth for Indonesian professionals and job seekers.

Tools & Technologies Used
- HTML5: Semantic structure and content
- CSS3: Custom styling with CSS variables and modern layout techniques
- JavaScript: Interactive functionality for FAQ accordion and smooth scrolling
- Google Fonts: Inter font family for modern typography
- Responsive Design: Mobile-first approach with CSS Grid and Flexbox

Features
- Modern Hero Section: Eye-catching gradient header with call-to-action
- Responsive Design: Fully responsive across desktop, tablet, and mobile devices
- Interactive FAQ: Accordion-style frequently asked questions section
- Smooth Scrolling: Navigation between page sections
- Testimonial Section: Client success stories and reviews
- Benefits Grid: Clear presentation of course advantages
- Professional Styling: Clean, modern design with consistent color scheme

Design Features
- Color Scheme:
  - Primary Blue: `#0077b5` (LinkedIn brand color)
  - Secondary: `#f5f5f5` (Light background)
  - Accent: `#4da0b0` (Teal for buttons)
  - Text: `#333333` (Primary text)
- Typography: Inter font family for modern, readable text
- Layout: CSS Grid and Flexbox for responsive layouts
- Animations: Smooth hover effects and transitions
- Box Shadows: Subtle shadows for depth and dimension

Responsive Breakpoints
- Mobile: < 768px (single column layout)
- Tablet: 768px - 1024px (adaptive grid)
- Desktop: > 1024px (full responsive grid)
